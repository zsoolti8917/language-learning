# F1 Repository and tooling
Status: done

## What was built
- pnpm 12 workspace: `apps/{api,web}`, `packages/{contracts,db,srs,ling,ai,testkit}`, `tools/{pipeline,evals}`, `e2e`. Each is `@app/<name>` with an empty `src/index.ts`. `@app/testkit` also exports `./mini`; `@app/ai` also compiles `prompts/`; `@app/api` exports `./*` (subpaths of `src/`, for tools and evals).
- Version catalog in `pnpm-workspace.yaml`, every dependency pinned exactly; packages reference it with `catalog:`.
- `.nvmrc` (24), TypeScript 7 project references (`tsconfig.base.json`, root `tsconfig.json`, `tsc -b` emits declarations into each `dist/`), Biome 2.6 (`biome.json`), Vitest 5 projects (`vitest.config.ts`, one project per package folder plus `root-scripts`).
- Dependency check: `scripts/deps-rules.mjs` (rules, pure) and `scripts/check-deps.mjs` (walks the workspace). Tested in `scripts/deps-rules.test.mjs`.
- `apps/web/vite.config.ts` with the React and Tailwind plugins, `index.html`, a minimal `src/main.tsx` and `src/index.css`.
- Root scripts from the Contracts tab; scripts of packages not built yet print the package that provides them (`scripts/pending.mjs`).
- CI in `.github/workflows/ci.yml`: `pnpm install --frozen-lockfile` and `pnpm check`.
- `AGENTS.md`, `CLAUDE.md`, `docs/{architecture,contracts,work-packages}.md`, `docs/handoff/TEMPLATE.md`, `.env.example`, `.gitignore`.

## How to run and test it
`nvm use && pnpm install --frozen-lockfile && pnpm check`. One package: `pnpm test --filter ling`.

## Differences from the specification, and why
- The dependency check is a small script of our own instead of dependency-cruiser: it has no TypeScript 7 coupling and encodes the module rule (API modules reach each other only through `ports.ts`) directly.
- Biome does not check Markdown (`!**/*.md`), because its Markdown formatter was not stable on the docs tables.
- pnpm 12 uses `allowBuilds` (not `onlyBuiltDependencies`) to allow esbuild's install script.
- `apps/web/vite.config.ts` sets `test.environment = 'jsdom'` already, so F7 can test components before F6.

## Known gaps and follow ups
- The "only `repo.ts` runs SQL" rule is not enforced by the script; reviewers check it.

## Notes for packages that depend on this one
- Packages export TypeScript sources (`./src/index.ts`); Vite, Vitest and tsx consume them directly. No build step for packages.
- Vitest has no globals: import `describe`, `it`, `expect` from `vitest`.
- A package needing its own test environment adds `vitest.config.ts` (or uses `vite.config.ts`) in its folder.
- In the cloud containers Node 24 lives in `/opt/node24/bin`; put it first on `PATH`.
- Playwright 1.65.1 matches the browsers preinstalled at `/opt/pw-browsers`.
